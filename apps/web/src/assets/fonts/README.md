# Interface fonts

Unmodified WOFF2 subsets extracted from the user-supplied HiDockNotes Frontend Redesign v1. Inter supplies the interface and document text; JetBrains Mono supplies timestamps and code. Only the embedded subsets are included. Other scripts fall back to system fonts.

The bundled files total about 250 KiB and load by character range. Vite fingerprints them and includes them in the PWA cache. No remote font service or new JavaScript package is required. Copyright and SIL OFL 1.1 terms are in OFL.txt and the root THIRD_PARTY_NOTICES.md.
